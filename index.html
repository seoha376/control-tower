PUBLIC GUIDE

Public guide to the AdSense operations dashboard

What Control Tower tracks

Control Tower is an AdSense operations dashboard for small website owners who need one place to review deployment health, approval status, revenue notes, and the next action for each site.

How the approval workflow works

Each website record keeps the site URL, repository URL, deployment state, AdSense review state, due date, and operator notes. The dashboard highlights sites that are still under review or need a follow-up before ads can run.

How synchronization is handled

Signed-in users can connect their own Google AdSense account. The server reads site approval status through the AdSense Management API and updates only the projects owned by that user.

What data stays private

Personal dashboards require GitHub login. Public pages explain the product, while private project records, revenue notes, connected account tokens, and owner-specific website lists remain protected by Supabase row level security.
