PRIVACY POLICY

Privacy Policy

Last updated: August 6, 2026

Control Tower stores website operations data for signed-in users. This may include project names, site URLs, repository URLs, deployment status, AdSense status, revenue notes, and next-action notes.

Authentication and account data

The app uses Supabase Auth with GitHub login. Authentication data is handled by Supabase and GitHub. Project records are associated with a Supabase user id so that each user can access only their own records.

Google AdSense connection

If a user connects Google AdSense, the server stores the refresh token in encrypted form and uses it to request site approval status from the Google AdSense Management API. Tokens are not exposed to the browser.

Analytics and advertising

The site may use Google Analytics, Vercel Web Analytics, and Google AdSense. These services may use cookies, web beacons, IP addresses, browser information, and similar identifiers to measure traffic, prevent abuse, and serve or evaluate ads.

Google explains how it uses data from partner sites at Google's partner sites policy page.

Data sharing

Control Tower does not sell personal data. Data may be processed by service providers needed to run the app, including Supabase, Vercel, GitHub, and Google services selected by the user.

Contact

For privacy questions, use the contact information on the Contact page.
